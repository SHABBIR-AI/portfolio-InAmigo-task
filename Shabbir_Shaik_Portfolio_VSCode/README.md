# Shabbir Shaik — Personal Portfolio

## Run in VS Code
1. Extract/open this folder in VS Code.
2. Open `index.html`.
3. Right-click it and choose **Open with Live Server** if you have the Live Server extension.
4. Or simply double-click `index.html` to open it in your browser.

## Before publishing
Edit `index.html` and replace:
- `your-email@example.com`
- LinkedIn URL
- GitHub URL

You can also add your real resume link to the "Download Resume" area later.

## Files
- index.html — portfolio content
- style.css — responsive modern dark design
- script.js — menu, scroll reveal and cursor effect
